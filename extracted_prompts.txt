Prompts para Antigravity – Mejoras de la auditoría ESPY
Cada prompt es una tarea completa que Antigravity puede ejecutar sola en tu computador: lee
los archivos, hace los cambios, corre las pruebas, guarda un punto de control en Git y te entrega
un informe.
Versión 3 (26 de octubre, tarde). Revisé la versión con la limpieza del CDP y el nuevo motor
UNSPSC. Los prompts 0 a 10 siguen vigentes; el prompt 0 ahora también ordena los scripts nuevos.
Se agregaron el prompt 11 (terminar y conectar el motor UNSPSC nuevo) y el prompt 12 (una sola
regla para el texto del CDP).
Cómo usarlos
1. Abre la carpeta ESPY_Contratacion_Automatizada de tu computador en Antigravity.
2. Detén el servidor (DETENER_SISTEMA_ESPY.bat) antes de cada prompt.
3. Abre una conversación nueva por cada prompt, copia el bloque completo y pégalo tal cual.
4. Usa el modo de agente (Agent / Planning) y aprueba los comandos de terminal que te pida.
5. Cuando termine, lee su informe, inicia el sistema y prueba en el navegador lo que indique la
sección "Prueba manual".
6. Orden recomendado: 0 → 12 → 1 → 2 → 3 → 11 → 4 → 5 → 6 → 7 → 8 → 9 → 10. Los urgentes son
0, 1, 2, 3 y 11. El 12 es corto y conviene hacerlo pronto porque toca documentos que ya se
están generando.
7. Si algo sale mal, pídele a Antigravity: "Revierte al último commit con git reset --hard HEAD".
